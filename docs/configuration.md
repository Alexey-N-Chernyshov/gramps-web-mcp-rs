# Configuration

All configuration is via environment variables.

| Variable                 | Default                  | Required when                                                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------ | ------------------------ | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GRAMPS_API_URL`         | —                        | always                                                        | Base URL of your Gramps Web instance, e.g. `https://gramps.example.com` or `http://localhost:5000`. Must include the scheme.                                                                                                                                                                                                                                                                                                                                                                                               |
| `GRAMPS_USERNAME`        | —                        | unless `MCP_OAUTH_ENABLED=true` or `GRAMPS_SYNC_TOKEN` is set | Gramps Web username for the shared service account.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `GRAMPS_PASSWORD`        | —                        | unless `MCP_OAUTH_ENABLED=true` or `GRAMPS_SYNC_TOKEN` is set | Gramps Web password for the shared service account.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `GRAMPS_SYNC_TOKEN`      | —                        | —                                                             | A Gramps Web persistent **sync token** (Settings → User settings → Account → Access tokens → Add sync device). The server exchanges it for a short-lived JWT via `/api/token/sync/` and re-exchanges it automatically as that JWT expires. Mutually exclusive with `GRAMPS_USERNAME`/`GRAMPS_PASSWORD` (setting both fails at startup). An empty string is treated as unset. Requires gramps-web-api 3.23+ — see [gramps-project/gramps-web-api#1032](https://github.com/gramps-project/gramps-web-api/pull/1032).         |
| `GRAMPS_READONLY`        | `false`                  | —                                                             | Set to `true` to hide write tools from the AI client. This is a convenience flag, not a security boundary — the account's own Gramps Web role still applies regardless of this setting. See [roles.md](roles.md) and [security.md](security.md).                                                                                                                                                                                                                                                                           |
| `MCP_TRANSPORT`          | `stdio`                  | —                                                             | `stdio` or `http`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `MCP_HTTP_HOST`          | `0.0.0.0`                | —                                                             | Bind host. Only used when `MCP_TRANSPORT=http`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `MCP_HTTP_PORT`          | `3000`                   | —                                                             | Bind port. Only used when `MCP_TRANSPORT=http`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `MCP_AUTH_TOKEN`         | —                        | —                                                             | Static bearer token protecting `/mcp`. An empty string is treated as unset. Ignored when `MCP_OAUTH_ENABLED=true` — if unset in that mode, OAuth is the only way in; if unset and OAuth is off too, `/mcp` has no authentication at all.                                                                                                                                                                                                                                                                                   |
| `MCP_ALLOWED_HOSTS`      | —                        | —                                                             | Comma-separated allowed `Host` header values (DNS-rebinding protection) for HTTP transport. If unset, only `localhost`/`127.0.0.1`/`::1` are allowed. Example: `your-domain.com:8888,localhost,127.0.0.1`.                                                                                                                                                                                                                                                                                                                 |
| `MCP_ALLOWED_ORIGINS`    | —                        | —                                                             | Comma-separated allowed browser `Origin` values for `/mcp`. Each entry needs a scheme (`http://`/`https://`); invalid entries fail at startup. If unset, any request carrying an `Origin` header is rejected (`403`) and no CORS headers are sent. If set, those origins pass through `/mcp` and are reflected in CORS headers; others still get `403`/no CORS headers. An entry may end in `:*` to allow any port, e.g. `http://localhost:*` for a browser-based tool like MCP Inspector. See [security.md](security.md). |
| `MCP_KEEP_ALIVE`         | `300`                    | —                                                             | HTTP session keep-alive timeout, in seconds. `0` disables session expiration.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `MCP_MAX_MEDIA_BYTES`    | `52428800` (50 MiB)      | —                                                             | Maximum size accepted for a media file read or upload.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `MCP_OAUTH_ENABLED`      | `false`                  | —                                                             | Turns on per-user OAuth 2.1 on the HTTP transport instead of the single static identity from `GRAMPS_USERNAME`/`GRAMPS_PASSWORD` or `GRAMPS_SYNC_TOKEN`.                                                                                                                                                                                                                                                                                                                                                                   |
| `MCP_OAUTH_STORAGE_KEY`  | —                        | when `MCP_OAUTH_ENABLED=true`                                 | Base64 of exactly 32 bytes, encrypting the on-disk OAuth store. Generate with `openssl rand -base64 32`.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `MCP_OAUTH_STORAGE_PATH` | `/data/oauth_store.json` | —                                                             | Where encrypted OAuth state (registered clients, sessions) is persisted. The default path matches the image's `/data` directory (owned by its non-root user) — mount a named volume there so it survives container recreation.                                                                                                                                                                                                                                                                                             |
| `MCP_OAUTH_PUBLIC_URL`   | —                        | when `MCP_OAUTH_ENABLED=true`                                 | This server's externally-visible base URL. Must be `https://`. Its path decides where the OAuth routes and discovery documents are mounted — see [endpoints.md](endpoints.md).                                                                                                                                                                                                                                                                                                                                             |

## Examples

Local, stdio:

```bash
GRAMPS_API_URL=https://gramps.example.com
GRAMPS_USERNAME=gramps-mcp
GRAMPS_PASSWORD=your-password
```

HTTP with a static token:

```bash
GRAMPS_API_URL=https://gramps.example.com
GRAMPS_USERNAME=gramps-mcp
GRAMPS_PASSWORD=your-password
MCP_TRANSPORT=http
MCP_AUTH_TOKEN=your-secret-token
MCP_ALLOWED_HOSTS=gramps-mcp.example.com
```

Sync token instead of username/password:

```bash
GRAMPS_API_URL=https://gramps.example.com
GRAMPS_SYNC_TOKEN=your-sync-token
```

HTTP with OAuth (no shared `GRAMPS_USERNAME`/`GRAMPS_PASSWORD` — each user signs in with their own):

```bash
GRAMPS_API_URL=https://gramps.example.com
MCP_TRANSPORT=http
MCP_OAUTH_ENABLED=true
MCP_OAUTH_STORAGE_KEY=<output of: openssl rand -base64 32>
MCP_OAUTH_PUBLIC_URL=https://gramps-mcp.example.com
MCP_ALLOWED_HOSTS=gramps-mcp.example.com
```

See the setup guides for how these are used in each deployment mode:
[local](setup-local.md), [LAN/VPN](setup-server-lan.md), [public server](setup-server-public.md).
